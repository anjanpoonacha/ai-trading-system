# CSS (Champion Swing Short)

## Overview

- Short selling setup: sell first, buy back later at lower price
- Used ONLY in bearish/weak market conditions when index confirms downtrend
- Traded in **Futures segment only** (~200 stocks available)
- 1 lot ≈ ₹7 lakhs contract value → minimum risk ₹20,000–30,000 per trade
- Holding period: **5–20 days** (typically exit within 7 days)
- Time frame: weekly (analysis) + daily (entries/exits)
- CSS is **optional** — primarily we are long-side traders
- Do NOT let short losses erode long-side gains

## Entry Conditions (SHORT)

### Index Conditions (Nifty 500)
1. **10 DMA and 20 DMA sloping DOWN**
2. **Index in pullback zone** — price has pulled back UP toward 10/20 DMA after a down swing
3. Do NOT short during active down swings — wait for pullback
4. Character change invalidates shorts: PPC + gap up + close above 20 DMA = stop shorting

### Stock Conditions
1. **Recent distribution characteristics** — stage 3 or stage 4 transition confirmed:
   - Rounding tops, head & shoulders, breakout failures
   - Frequent NPCs, breakdowns below structure
2. **Pullback toward moving average** — preferably 50 DMA or 200 DMA; 20 DMA acceptable if quality is high
3. **Trigger**: break below previous day's low (candle near the MA)

### Entry Execution
- Enter on **break of previous day's low** when stock is near 50/200/20 DMA
- If intraday swing > TRP before trigger breaks → **skip the trade** (extended entry)
- Small contracted candles near MAs = ideal trigger bars
- Earnings gap bounce-backs that pull to MAs = good setups (post-earnings)

## Stop Loss

- **1.5 × Average TRP** of the stock (broader than CDS due to stage 3/4 volatility)
- Alternatives:
  - Technical level: previous swing high
  - TRP-based: 3–4% from entry
  - Combination: 50% at technical, 50% at TRP
- Handling: same as CDS — allow 30–60–90 min sustain beyond SL before exit

## Target / Exit

### Key Principles
- **Exit quickly** — stocks fall differently than they rise; pullbacks are SHARP
- Settle for **lower R multiples** (1.5R–3.6R typical; don't aim for large Rs)
- Exit only at close (last 30 min) except stop loss
- Use **index chart for exit timing** (unlike long trades)

### Exit Method
1. **Index extended on downside** (4–5 bar down swing, large NPC on index) → book 30–50% gains
2. **Stock hits previous support level** → book 30–50%
3. **Trail stop loss aggressively** using recent highs (last 3–4 candles)
4. **Gap downs** → take full remaining exit immediately (don't wait)
5. Typical exit pattern: 30% → 40% → 30% or 50% → 50%

### Index Exit Signals
- Down swing of 4–5 bars on index = likely pullback coming → partial exit
- Index extended ≥5% from swing high → strong exit signal
- Gap down on index = take profits

### Earnings Rule
- Same as long trades: don't enter ahead of earnings
- If holding with no profit cushion → exit before earnings
- If holding with cushion → okay to hold through

## Extended Entries

- **Avoid entries substantially away from previous swing high**
- If confirmation candle comes after 4–5 consecutive red candles from swing high → SKIP
- If 2 large red candles already consumed most of the swing → SKIP
- Valid entry = immediately after an upswing/pullback or short consolidation
- Need congestion/contraction + confirmation candle near swing high or MA

## Re-Entry Within Same Bear Phase

- After exiting a trade, wait for next index pullback to attempt new shorts
- Multiple setups can be taken within same pullback zone
- Pullback zone = between 10 DMA and 20 DMA on index
- Once index makes a new down swing (breaks below pullback zone) → stop entering, wait for next pullback
- Same stock can be re-shorted if it pulls back again to MA and produces new trigger
