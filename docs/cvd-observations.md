## Session: 2026-08-15

### Methodology developed

- CVD anchor resets to zero at the start of each anchor period. Values are only comparable within the same window — never across a reset.
- Shorter anchor (3M) gives earlier signals than longer anchor (6M/12M). A stock can look bearish on 6M CVD while 3M CVD is already positive — that divergence is worth noting.
- CVD should be read as OHLC, not just close. `tail` (close−low) = intrabar buyer recovery. `wick` (high−close) = intrabar demand failure. `tail >> wick` on high volume = buyers in control. `wick >> tail` = sellers absorbed the demand.
- The working question for any stock: was there a CVD tell before any prior significant move? Is anything similar happening now?
